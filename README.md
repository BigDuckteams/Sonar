# Sonar

Личный музыкальный плеер для Android: ваша скачанная музыка и полные треки независимых артистов — в одном приложении, без регистрации. Только полные треки, без превью.

> Sonar — не клиент Spotify и не «качалка». Каталог Spotify бесплатно и без аккаунта слушать нельзя, а обход защиты — это нарушение авторских прав. Поэтому Sonar берёт музыку только из источников, где это разрешено (см. ниже).

## Что умеет

- **Музыка с телефона.** Находит аудиофайлы в памяти телефона (загрузки, папка Music и т. д.): список треков, папки, исполнители, сортировка, фильтр. Файлы никуда не копируются и не отправляются.
- **Полные треки без аккаунта.** Тренды по жанрам и поиск по [Audius](https://audius.co) — платформе независимых артистов.
- **YouTube внутри Sonar.** Вкладка с официальным мобильным YouTube: песни любых исполнителей целиком, например с официальных каналов групп. Играет, пока приложение открыто: при сворачивании видео встаёт на паузу (фоновое воспроизведение — функция YouTube Premium), а пока видео играет, экран не гаснет.
- **Один поиск:** телефон + Audius. Песни крупных лейблов бесплатно целиком есть только на официальных сервисах, поэтому под результатами есть кнопка YouTube (открывает этот запрос во вкладке YouTube) и переход в Яндекс Музыку.
- **Воспроизведение в фоне**, управление с экрана блокировки и из шторки уведомлений (нативный движок на Media3).
- Очередь («играть следующим», «в очередь», удаление), перемешивание, повтор, скорость 0.75–2×.
- **Таймер сна** с плавным затиханием (в том числе «после этого трека»).
- Избранное, плейлисты из любых источников, история и «Часто слушаете».
- Автопродолжение: когда очередь с треками Audius кончается, подбираются похожие того же жанра (отключается в настройках).

## Запуск для разработки (в браузере)

```bash
npm install
npm start      # затем откройте http://localhost:8081
```

В браузере работают интерфейс, поиск и воспроизведение; музыка с телефона и фоновое воспроизведение — только на Android.

## Установка на телефон (Android)

Плеер использует нативный модуль, поэтому в Expo Go приложение не запустится — нужна сборка.

**Вариант 1 — облачная сборка APK (проще всего, ничего не ставить на компьютер).** Нужен бесплатный аккаунт на [expo.dev](https://expo.dev).

```bash
npm install
npx eas-cli@latest login
npx eas-cli@latest build --platform android --profile preview
```

По окончании сборки EAS выдаст ссылку на APK — откройте её на телефоне и установите (разрешите установку из этого источника).

**Вариант 2 — локальная сборка.** Нужны JDK 17 и Android SDK (Android Studio), телефон с включённой отладкой по USB:

```bash
npm install
npx expo run:android
```

При первом запуске Android спросит доступ к аудио (для раздела «На телефоне») и, на Android 13+, разрешение на уведомления (для управления из шторки).

## Состояние проекта

Проверено: типы (`npm run typecheck`), сборка веб-версии, интерфейс главной, поиска и плеера в браузере. Вкладка YouTube в браузере показывает только кнопку «Открыть YouTube» — встроенный YouTube работает в приложении на телефоне и там ещё не проверялся.

**Ещё не проверено на настоящем телефоне:** фоновое воспроизведение, управление с экрана блокировки, чтение музыки из памяти, таймер сна. Если что-то из этого работает не так — это главное, что нужно проверить первым делом.

Известные ограничения и идеи на потом:

- Названия и исполнители файлов с телефона берутся из имён («Исполнитель - Название.mp3»), а не из тегов; обложек у них пока нет.
- Эквалайзер, кроссфейд, офлайн-кэш, Android Auto (библиотека плеера это умеет).

## Источники и лицензии

- **Audius** (`api.audius.co`) — музыку загрузили сами авторы; Sonar только проигрывает её через публичный API.
- **[@rntp/player](https://rntp.dev)** (звуковой движок) бесплатен для личного некоммерческого использования; для публикации приложения (например, в Google Play) нужна его коммерческая лицензия.
